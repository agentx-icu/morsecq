# 离线桌面外壳

桌面外壳管理窗口大小和位置、关闭到托盘、显示/隐藏/声音/退出菜单及固定的 MorseCQ 标题。AppServices 在语言变化时更新托盘文案，并在退出前等待本地学习数据与设置写入。没有未读消息状态或聊天路由。实体键绑定保存在本机，可在“我的”编辑。

使用 window_manager、tray_manager、screen_retriever 插件；移动平台不启用这些适配器。窗口、托盘及屏幕测试替身验证持久化、故障处理和本地化。

关闭窗口默认退出；“我的”提供已保存的继续在托盘运行选项。Linux 隐藏前检测真实 StatusNotifier 宿主。
只有接入真实声音控制器时才显示托盘声音项。最大化、全屏或最小化时保留正常窗口几何；再次激活会先恢复最小化窗口。
macOS 原生重开通过 Dart 通道同步可见性；显式退出在持久化后终止。DesktopInstance 从启动至进程退出持有整个本地存储的所有权，测试可显式释放。
