MorseCQ is a Morse code trainer: Koch lessons, copy and sending drills, a QSO
simulator, a reference handbook, a translator and decoding from the
microphone.

- **iOS / iPadOS (App Store):** a purely offline trainer. It has no chat, no
  account and makes no network connection of its own.
- **Other builds (Android, macOS, Linux, Windows, self-built):** the same
  trainer plus a serverless Morse chat over the [Tox](https://tox.chat)
  peer-to-peer network, end-to-end encrypted, with no MorseCQ server.
