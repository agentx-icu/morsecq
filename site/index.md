# MorseCQ

MorseCQ is an account-free offline Morse code trainer. Start with hearing dit/dah and K/M, then guided recognition and sending, independent Koch challenges and spaced review. Practice summaries show what needs work; simulated radio QSOs, Morse reference, audio decoding and radio tools support continued learning. For Morse chat, use [DitMesh](https://github.com/agentx-icu/ditmesh).
