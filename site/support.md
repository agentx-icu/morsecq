# Support

## Microphone

Open **Reference → Listen → Start** to decode Morse code from the microphone. If Listen cannot start, check the system microphone permission and make sure the input is available. If decoding is unreliable, move the sound source closer to the microphone.

## Find support in the app

In v1.0.1, **Me → About → Support and contact** opens this page. In builds with offline help, use **Me → Privacy and permissions → Technical support**.

## Report a problem

Include the device, operating system, app version if known and steps to reproduce the issue. If **Me → About → Copy local diagnostics** is available, you can attach its output. Share learning files or recordings only if you choose to. Open a [GitHub issue](https://github.com/agentx-icu/morsecq/issues).

For Morse chat, use [DitMesh](https://github.com/agentx-icu/ditmesh).
