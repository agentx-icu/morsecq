# Privacy policy

MorseCQ collects no personal data and has no account, registration, chat service, analytics or advertising. Learning history, settings, materials and recordings stay on your device. Microphone permission is used only when you start live Morse decoding. Learning-material file selection, sharing and opening support pages are explicit user actions handled by the operating system. Android allows operating-system backup and device transfer of the local learning directory and settings. Availability depends on the user’s backup settings and platform limits; Android cloud backup has a 25 MB quota. iOS backup remains controlled by the system. Diagnostic logs contain error types and stack frames, omit exception messages and learning contents, stay on-device, and are copied only by an explicit action in Me. Uninstalling or clearing learning data can remove local records and recordings.
