# 进阶学习

MorseCQ 的进阶学习参考 [CW Academy Intermediate Curriculum v2.1](https://cwops.org/wp-content/uploads/2025/06/Practice-Instructions-Intermediate-ver.2.1.htm) 的整词听辨、通联信息提取、短故事脑内听抄、清晰发报与竞赛交换方向。应用内练习文本为原创离线内容，不附带课程原始录音，也不代表 CW Academy 认证或背书。

## 跨次错题本

「学习 → 跨次错题本」保留错误原题、首次和最近答案、原字符速度与有效速度、干扰条件以及练习日期。抄报与听懂练习的错误都可以进入错题本；信息理解题保留原音频文本和问题，以语义答案评分。

重练从原题开始，使用原速度与原干扰条件。两个不同日期的独立、完整正确作答才标记为已掌握；同一天反复正确只算一天，重播或显示答案不增加掌握证据。再次答错会清除此前的恢复证据。错题按原题和训练条件归组，列表有容量上限，提交 ID 防止重复记账。

## 整词与整句听懂

「学习 → 脑内听抄」提供整词、短句、QSO 信息、POTA 信息和短故事。听完才开放作答；重播、显示答案以及包含未学字符的体验均标记为辅助练习。QSO 练习提取呼号、姓名、地点与信号报告；POTA 提取双方呼号、公园编号和信号报告；故事回答人物、地点、时间和行为问题。

理解成绩按问题统计，保存在独立记录中，不转成逐字符抄报准确率，不更新科赫课程或字符间隔复习。错题重练保存原题问题快照，避免以后题库或已学字符变化导致重练内容改变。

## 目标路线

「学习 → 学习目标」提供第一次通联、日常交谈与脑内听抄、竞赛交换三条路线。可查看当前证据、缺口和直接练习入口。路线采用 10、13、15、18、20、25 WPM 的可选速度阶段；首次通联路线到 13 WPM，交谈路线到 20 WPM，竞赛路线到 25 WPM。

里程碑需要最近 28 天内至少两次独立练习达到 90% 准确率及所需有效速度，并满足各能力的最小样本量。过期、辅助、未来日期、速度不足或样本不足的记录不通过里程碑。模拟通联使用首次答对的阶段比例，不以字符回显准确率代替协议能力。

初学者仍沿点划、K/M、引导识别和独立字符课程前进。课程通过后，每日计划将课程部分替换为相应目标的听懂训练与互动通联，保留复习和发报。目标切换只重排尚未开始的步骤，已开始步骤保留其速度、内容和成绩。

## 模拟通联

保留短通联、回答 CQ 和主动呼叫 CQ；增加竞赛交换与 POTA 公园间通联。竞赛交换验证呼号、RST 和序号；POTA 验证双方呼号、公园编号与 RST。对方会更正信息，需要正确确认。

可通过 AGN 请求完整重发，通过 QRS 请求降速，也可请求仅重发已经听到的 CALL、RST、NAME、QTH、NR 或 PARK 字段。重发不推进阶段且属于辅助。屏幕发报和文字作答均可完成协议练习，文字作答明确记录为辅助。草稿保留场景、速度、文本和计划归属，可在重新打开应用后继续。

## 保存与验证

错题、听懂记录和目标与 `TrainerProgress` 一同原子写入当前本地学习档案。旧档案缺少新字段时使用安全默认值；清除学习数据时这些内容随档案删除。练习提交 ID、真实文件重开、跨日重练、辅助标记、计划完成与手机大字号布局均有自动测试。
