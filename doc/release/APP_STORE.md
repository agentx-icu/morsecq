# App Store submission (iOS / iPadOS)

**Strategy (2026-10-07):** the App Store build is MorseCQ as a **purely
offline Morse trainer** — no chat, no identity, no network connection of its
own. It is selected at build time (`MORSECQ_CHAT=false`, see
`apps/morsecq/lib/di/app_features.dart`) and produced only by
`tool/build_ios_store.sh`. Android, desktop and self-built binaries keep the
Tox chat. Other decisions: licence **GPL-3.0**; **no China mainland** listing;
no e-mail anywhere (support is GitHub issues); signing is configured
separately.

## 3. Public site

`site/` holds the privacy policy, terms of use and support page (English and
Chinese), distinguishing the offline App Store version from the chat builds.
`.github/workflows/pages.yml` deploys it on pushes to `master`. The support
contact is GitHub issues (`support_url` in `site/_config.yml`); there is no
e-mail (Guideline 1.5 needs a working contact, which the support page gives).

## 4. Version and build

- `apps/morsecq/pubspec.yaml` `version: 1.0.0+4` → `CFBundleShortVersionString`
  1.0.0, `CFBundleVersion` 4. Every upload needs a higher build number.
- Build (after signing is configured): `tool/build_ios_store.sh` from the
  repository root. It writes the gitignored `ios/Runner/Info-Store.plist` and
  `ios/Flutter/Store.xcconfig`, runs `pod install` without Tim2ToxFFI, runs
  `flutter build ipa --release --dart-define=MORSECQ_CHAT=false`, then fails
  unless the archived app (and the IPA, when exported) has no
  `tim2tox_ffi.framework`, no libsodium / toxcore symbols, the privacy
  manifest, and `ITSAppUsesNonExemptEncryption = false`. On exit it restores
  the chat build's pods. `tool/build_ios_ffi.sh` is **not** needed for it.
  `--no-codesign` gives a verified unsigned archive.
- Upload `apps/morsecq/build/ios/ipa/*.ipa` with Transporter or `xcrun altool`,
  then check the upload e-mail for ITMS warnings.
- Never upload an iOS build made without the script: a plain `flutter build
  ipa` is the chat build.

## 5. App Privacy ("nutrition label")

**Data Not Collected.** The store binary has no server, no account, no
analytics, advertising, crash reporting or tracking SDK, and no network code
of its own; learning data and microphone audio are processed on the device
only. Tracking: **No**.

## 6. Privacy manifest

`apps/morsecq/ios/Runner/PrivacyInfo.xcprivacy` (Runner target resource): no
tracking, no collected data; UserDefaults `CA92.1`, file timestamps `C617.1`.
Flutter and the plugins ship their own manifests. The Tim2Tox framework (and
its manifest, `tool/ci/ios/tim2tox_ffi.PrivacyInfo.xcprivacy`) is not in the
store binary.

## 7. Export compliance

The store binary contains no non-exempt encryption: the Tox stack (c-toxcore,
libsodium) is left out by the Podfile, and the remaining code only uses
Apple's OS crypto (HTTPS by the system, Keychain). The store script builds
from `Info-Store.plist` with `ITSAppUsesNonExemptEncryption = NO`, so App
Store Connect asks no encryption questions and no French declaration or US
self-classification report is needed for this binary. (The chat builds keep
`YES` in `Info.plist`; they are not distributed through the App Store.)

## 10. Screenshots

`tool/screenshots/capture.sh --platforms ios,ipad` boots the iPhone 17 Pro Max
(6.9", 1320×2868) and iPad Pro 13-inch (2064×2752) simulators and captures
the **offline build** (`MORSECQ_SHOT_VARIANT=offline`: Learn, statistics,
training settings, receive drill, send practice, reference, translator,
Listen, Me) as RGB PNGs; any other size or an alpha channel is refused.
Upload from `doc/screenshots/ios/<locale>/` and `doc/screenshots/ipad/<locale>/`
(`en` → English, `zh` → Simplified Chinese). Suggested order: `learn_home`,
`receive_drill`, `send_practice`, `stats`, `reference`, `translator`,
`listen`, `training_settings`, `me`.

## 11. Licence

MorseCQ is GPL-3.0. The owner chose to ship under GPL-3.0 knowing the
long-standing debate about GPL and App Store terms; the source is public and
linked from the app (Me → About) and the terms page. The store binary does
not include Tim2Tox or c-toxcore.

## 12. The chat builds

Android, macOS, Linux and Windows (and self-built binaries) keep the Tox chat
with block, the versioned community-guidelines gate (`kTermsVersion` 2, no
report flow) and the `ITSAppUsesNonExemptEncryption = YES` plist. If an iOS
chat build is ever distributed through App Store Connect, it needs the chat
answers instead (encryption: standard algorithms, ECCN 5D992.c, annual BIS
self-classification report, French declaration; Guideline 1.2, which then
requires a report mechanism again).
