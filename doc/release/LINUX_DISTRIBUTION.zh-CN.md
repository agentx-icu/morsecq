# Linux 中国区分发准备

## 目标渠道

1. deepin 应用商店 / 统信生态：优先适配，提交 `.deb` 或商店要求的玲珑包。
2. 麒麟、openKylin 等国产发行版：在 deepin 包稳定后再做兼容性验证和生态提交。
3. Flathub：作为跨发行版补充渠道，需要把当前二进制演示模板改成源码构建。
4. Snap Store：保留为国际渠道，先完成 core24、GNOME 扩展和严格权限验证。

## deepin/UOS 要求

- 必须准备可安装、可卸载且可升级的 Linux 包；当前仓库 CI 产出 DEB、RPM 和 tar.gz。
- deepin 社区投递要求应用资料完整、应用可正常运行，并按商店分发机制处理更新。
- 不要在商店包内静默更新或额外安装卸载入口；更新和卸载交给系统软件中心。
- 提交前在 deepin/UOS 实机或对应虚拟机验证启动、麦克风、托盘、文件选择、升级和卸载。
- 应用图标、中文名称、隐私政策、支持地址和 GPL-3.0 许可证信息要保持一致。

## 当前阻塞

- Flathub 模板目前是二进制演示，不能直接作为正式 Flathub 提交；需要改成可复现源码构建。
- Snap 模板仍需 native snapcraft 验证，确认 strict confinement 下音频、托盘和文件访问权限。
- 国产发行版包需要在真实系统上做安装与回滚测试，云端 CI 通过不等于商店验收通过。
