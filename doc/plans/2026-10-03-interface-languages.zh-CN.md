# 界面语言扩展

**目标：** 在英文、简体中文界面基础上，新增繁体中文、日语、韩语、德语、
法语、西班牙语、葡萄牙语和俄语。文档继续只维护英文和简体中文。

**设计：** 沿用现有 Flutter gen-l10n 流程，每份
`apps/morsecq/lib/l10n/app_<locale>.arb` 完整翻译模板的 656 条消息。
生成的 `S.supportedLocales` 驱动语言选择器、控制器、通知和桌面外壳。
保留产品名、占位符类型和协议标识。俄语使用 one/few/many/other 复数；
繁体中文使用 `zh_Hant`，保留已有 `zh` 偏好的含义。
参考手册的数据表释义和记忆提示继续使用英文/简体中文数据，繁体中文使用中文
数据表，其他新增界面语言沿用现有英文回退。

部分翻译会让新界面残留大量英文；重构语言选择机制会重复已有能力。
完整 ARB 翻译可以直接融入当前结构。

## 实施与验证

1. 验证现有 i18n 测试基线。在 `test/i18n/shipped_locales_test.dart`
   增加十种语言、繁体中文匹配、持久化、后台字符串、俄语复数回归测试。
   在 `language_settings_tile_test.dart` 验证 320 × 568 手机屏幕上每个新增
   语言选项的滚动、切换和返回跟随系统。先运行测试，确认因缺少语言而失败。
2. 新增八份完整 ARB，保留所有 ICU 占位符和有意义的零值提示。
   在 `apps/morsecq` 运行 `flutter gen-l10n`，不手工编辑生成文件。
3. 更新假定法语不受支持的测试。同步根目录 README、本地化 README
   的中英文版本，以及本地化配置注释，说明支持语言和文档策略。
4. 运行 i18n 测试、排除 `needs-native` 的应用测试、应用静态分析、
   复杂度/导入守卫和字符串迁移检查。检查翻译中非预期的英文原文残留，
   验证 ICU 的运行结果。
