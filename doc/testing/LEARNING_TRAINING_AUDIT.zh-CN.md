# 学习与训练审计 — 2026-10-09

审计范围是当前应用所有学习、训练和录音练习入口，检查可达性、完成和离开流程、计分归属、辅助标记、保存失败重试、重开及清除学习数据。修复沿用 `codex/cw-advanced-learning` worktree；问题先以失败测试复现，再修复和回归。

## 逐项覆盖

| 学习／训练项 | 流程与信用 | 持久化与中断 |

## 当前功能边界

- 未完成普通听抄／发报输入和材料编辑草稿属于会话状态，离开确认后丢弃；通联草稿支持跨次恢复。
- 中文电码目前提供数字听抄和双向码表回忆，没有专门的中文电码发报训练入口。
- 发报节奏详情会持久化，当前结果页可查看；尚无跨次历史详情重开／收藏界面，底层详情及收藏接口已有测试。
- 材料 `version=1` 表示文件格式版本，没有修订历史浏览或撤销；已开始练习与错题保存原内容快照。
- 录音选段保存为音频材料，不会自动生成文字训练材料。共享 JSON 整库仍限制 1 MiB，超限导出明确失败。
- 本轮原生验证平台为 macOS；其他平台行为依赖已有跨平台代码与测试，本轮未在 Android、iOS、Windows 或 Linux 实机复测。USB／BLE 电键、麦克风录入及真实系统设备拔出未做硬件验证；对应界面使用测试替身，真实文件与 DSP 单独验证。原子写入和备份恢复测试不等于断电持久性证明。
