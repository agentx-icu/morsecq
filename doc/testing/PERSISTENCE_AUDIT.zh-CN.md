# 离线持久化审计 — 2026-10-08

MorseCQ 在本地保存学习及偏好，安装后直接打开学习。`<support>` 是 path_provider 返回的应用平台支持目录；`<learning>` 为 `<support>/morsecq/guest`。数据不依赖进程当前目录，也不写入安装包内部。

| 持久化内容 | 位置 | 保存与重载行为 |
| --- | --- | --- |
| 课程完成、入门时间、识别节奏、引导发报阶段、SRS 卡片、计划步骤、完成的训练历史、跨次错题本、听懂记录和所选学习目标 | `<learning>/training/progress.json` | 校验后原子替换 JSON，保留上一次有效文件；新控制器恢复已提交数据。 |
| 训练速度、播放及教学默认值 | `<learning>/training/settings.json` | 本地设置经过校验并串行保存。 |
| 素材、工作台文档、录音元数据、发报节奏详情、中文电码练习、通联草稿及停放的通联结果 | `<learning>/training/docs/` | 命名 JSON 文档原子替换，并可恢复上一次保存。 |
| 录音音频 | `<learning>/media/recordings/` | 元数据仅接受安全的相对录音文件名。`<learning>/media/recordings_kept.json` 记录备份恢复时必须保留的录音。 |
| 语言、外观、参考播放、解码及实体键偏好 | `<support>/settings.json` | 共用文件键值存储；风格与明暗模式一起写入 `appearance.preferences`，默认 Modern / 跟随系统。外观在保存成功后生效，失败保留已提交状态。 |
| 桌面窗口尺寸、最大化及托盘偏好 | `<support>/settings.json` | 按当前显示器验证尺寸，关闭到托盘和退出遵循已保存设置。 |

实时音频、麦克风缓冲、按键状态、当前页面、翻译器草稿及未完成训练输入属于会话状态；完成的训练和选择的默认值会持久化。素材及媒体可通过各自工具分享，与整个应用备份是不同操作。可移植学习备份的存储层已经存在（见[学习架构](../architecture/OFFLINE_LEARNING.zh-CN.md#备份存储层)），但尚无面向用户的操作。

`AppScope` 一起等待偏好、语言、实体键配置和共享训练控制器保存。偏好保存失败会保留待写快照以供重试，其他设置不能清除该失败。进入后台时使用可用的平台后台任务桥接；桌面退出等待持久化，并传递尚未解决的错误。确认清除学习数据后，先保存并退役当前控制器，再删除本地训练 / 媒体文件，重建空白控制器，避免延迟写入恢复已经清除的数据。语言、外观和窗口等应用偏好仍可使用。

回归覆盖并发文件写入、损坏 JSON 恢复、偏好失败 / 重试和外观重启；首次启动、后台保存、清除持久化和学习界面重载；`integration_test/persistence_test.dart` 在真实平台重新打开学习及偏好存储。`integration_test/storage_contract_test.dart` 在设备文件系统上覆盖进程被杀前的生命周期保存屏障、与清除竞争的迟到写入、损坏进度文件的恢复以及快速连续的未等待写入；`integration_test/app_storage_lifecycle_test.dart` 驱动真实应用，依次经过带原生后台任务的切入后台、桌面退出钩子和“我”页面的确认清除，每项之后都重新启动应用。桌面 E2E 会在 macOS、Linux 和 Windows 运行全部集成测试及真实界面导航。最新精确测试数量、CI 链接、设备证据及产物校验统一维护于[验证记录](../VALIDATION.zh-CN.md)和[英文版本](../VALIDATION.md)。可通过 `tool/test_pyramid.sh` 重现门禁与测试，截图和视觉矩阵详见[截图指南](../../tool/screenshots/README.zh-CN.md)。

应用支持目录无法打开时，偏好会记录错误并退回内存，无法在重启后恢复；学习存储失败显示可重试状态。原子替换及上一次有效文件降低不完整文件风险，但不证明断电或强制杀进程的持久性。

## 跨平台更新 — 2026-10-22

桌面在任何设置或学习存储打开前取得整个应用支持目录的进程锁，保留到进程退出；后续启动通过认证的本机 IPC 请求激活原窗口。
未来版本的进度/设置格式以 `UnsupportedDataVersion` 穿透原子加载器与控制器，显示需更新状态，不重命名、不用备份覆盖，也不写入。
连续损坏保留不同恢复副本。电报码回忆原本已有写保护，现在 codec 也显式拒绝未来格式。
Android 改为允许系统备份/迁移本地学习目录和设置，受系统设置与 25 MB 云备份限额约束，真实恢复/迁移仍需设备验证。
关闭窗口默认退出；“我的”提供持久化托盘选项，仅有真实宿主时可用。原生可取消退出请求等待保存。
强制终止与 Windows 会话结束回调不在本次已验证保证内。
