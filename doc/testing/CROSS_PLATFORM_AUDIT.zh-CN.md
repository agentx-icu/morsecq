## 验证证据

- 根分析零问题；tool 分析、复杂度、导入、UI 字面量、共享 pin gate 通过。
- `tool/test_pyramid.sh --level unit`：五共享包与 tool 全部通过。
- 应用完整套件曾为 1163 通过、753 个默认真实字体布局跳过。最后增补后的完整运行有 1177 通过、753 跳过，两项新增 Android 时制测试仅在平台 debug 变量恢复时触发框架检查；改用 TargetPlatformVariant 后该文件 4 项通过，未重复其余未变化测试。
- 实际字体布局：775 项通过（真实字体）。使用上游 noto-cjk 的 NotoSansCJK、系统 Menlo/Songti，字体只留在本机 build 目录。
- `TZ=Europe/Berlin` 统计回归通过，时制与周日起始 Widget 有覆盖。
- Android 证书校验四个回归，截图导入、发布资产与 Apple 缓存回归本机执行。
- Mac universal release 57.0 MB；原生托盘隐藏/重开保持 PID 与“我的”，关闭托盘模式时关闭退出 0，Cmd-Q 后无进程。window_manager 在终止时可能输出 engine response handle 警告；进程退出不等于已验证所有保存路径。
