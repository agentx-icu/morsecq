# 离线产品截图

每个平台、每种语言均包含九个场景：learn_home、stats、training_settings、receive_drill、send_practice、reference、translator、listen、me。

2026-10-08 的真实离线应用截图覆盖 macOS（1280×800）、iPhone（1320×2868）、iPad（2064×2752）和 Android（823×1829），均包含英文与简体中文。Android 尺寸来自实际模拟器捕获，不作为 App Store 营销尺寸。Linux 与 Windows 图库由按需启用的 E2E CI 生成。
